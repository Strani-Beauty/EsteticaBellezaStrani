## 3. Rutas de solución (pendientes)

### A. Emulador con WHPX (recomendado — Windows 10 Pro)

Sin tocar SDK Manager ni AEHD:

1. **Panel de control → Programas → Activar o desactivar características de Windows**.
2. Marcar **"Plataforma de hipervisor de Windows"** (Windows Hypervisor Platform).
3. Reiniciar.
4. Verificar:
   ```powershell
   & "C:\Users\Jaime\AppData\Local\Android\sdk\emulator\emulator.exe" -accel-check
   ```
   Debe indicar `WHPX is installed and usable`.
5. Lanzar y probar:
   ```powershell
   flutter emulators --launch Pixel_10_Pro
   flutter devices
   flutter test integration_test/app_test.dart -d emulator-5554
   ```

### B. Emulador con AEHD (alternativa)

1. Android Studio → SDK Manager → SDK Tools → "Android Emulator Hypervisor Driver (installer)" → Apply.
2. Instalar el driver (como administrador):
   ```powershell
   & "C:\Users\Jaime\AppData\Local\Android\sdk\extras\google\Android_Emulator_Hypervisor_Driver\silent_install.bat"
   ```

### C. Dispositivo físico POCO X3

1. Verificar **"Instalación mediante USB"** (interruptor distinto de "Depuración USB").
2. Desactivar **"Optimización MIUI"** (Opciones de desarrollador).
3. Desinstalar a mano la app atascada o forzar:
   ```powershell
   & "C:\Users\Jaime\AppData\Local\Android\sdk\platform-tools\adb.exe" shell pm uninstall --user 0 com.example.esteticaybellezastrani
   ```
4. Reejecutar:
   ```powershell
   flutter test integration_test/app_test.dart -d 5c46db5c
   ```
